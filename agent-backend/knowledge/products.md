# Anvil 平台产品知识库

## 平台概述

Anvil 是一套面向外贸、跨境电商和工业制造企业的智能 AI 客服 + 线索管理 SaaS 平台。
核心价值：多语言 AI 客服 24×7 响应、访客行为追踪与意向评估、渐进式留资与线索自动入库。

---

## 核心产品模块

### 1. 智能对话工作台（N2）
- AI 客服自动接待访客/线索/会员
- 支持 AI-人工无缝切换（转人工 / AI客服）
- 实时 AI 副驾：意向打分、情绪弧度、回复建议
- 多租户隔离，支持多个网站同时接入

### 2. 访客洞察（N1）
- 实时追踪访客行为：页面浏览时长、滚动深度、CTA 点击
- 匿名访客身份识别（IP + 设备指纹）
- 历史访问轨迹与意向热力图
- 与 N7 线索池联动：访客留资后自动升级为线索

### 3. 线索池（N7）
- 留资后才生成线索（非进站即线索）
- 线索状态：待处理 / 跟进中 / 已转化 / 无效
- 支持线索字段自定义（与 N3 渐进式表单同源）
- 一键转客户，进入 N6 客户管理
- CRM 同步：支持写入 TwentyCRM / Salesforce

### 4. 客户管理（N6）
- 客户列表：全部客户 / 客户分组 / 客户设置
- 客户 360：行为轨迹 / 会话记录 / 客户画像 / 工单
- 支持个人会员与企业客户两种类型
- 客户来源：后台添加 / 线索转化

### 5. 智能体配置（N3）
- 系统提示词（System Prompt）可视化编辑
- 渐进式留资表单：字段启用/必填开关，与线索池同源
- 技能配置：RAG 知识库 / 网络搜索 / 自定义工具
- 触发规则：会话轮数、关键词、意向分阈值

### 6. 工单管理（N8）
- 售后导向工单类型：产品故障 / 退换货 / 物流配送 / 发票账单 / 账号权限 / 投诉建议
- 支持关联客户（工单在客户 360 可见）
- SLA 管理与优先级评分
- 工单类型可配置

### 7. 转化看板（N10）
- 漏斗：访客 → 有效留资 → 合格线索 → 转客户 → 续约留存
- 多维度指标：转化率 / 平均处理时长 / AI接待占比

## 技术特性

- 多语言支持：中文、英语、俄语、西班牙语等 15+ 语言
- 模型支持：OpenAI / Claude / 本地化模型
- 部署方式：SaaS 云端 / 私有化部署
- 接入方式：嵌入式 JS 代码片段（一行代码）/ API 对接
- 数据安全：数据隔离、审计日志、GDPR 友好

---

## 适用行业

- 外贸 B2B：跨境询盘转化、多语言客服
- 工业制造：售后支持、技术问询
- SaaS 软件：试用转化、续约管理
- 跨境电商：订单售后、退换货处理
