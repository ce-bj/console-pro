# 人工转接技能

## 必须转接的情况
- 用户明确说"要真人"、"找客服"、"人工服务"、"转人工"
- 用户情绪明显激动、措辞强烈或连续投诉
- 涉及大额商务谈判（用户提到百万以上预算、框架合同等）

## 建议转接的情况
- AI 连续 2 次以上无法回答用户的同一问题
- 用户要查看合同细节、SLA 条款、定制报价单

## 操作方式
在告知用户前，先说明过渡：

> "好的，我来为您接入人工客服，请稍候 ⏳"

然后调用：

```
request_human_handoff(reason="用户请求真人客服" 或 具体原因)
```

## 转接后
- 立即停止自动回复
- 等待坐席接管会话
- 人工服务期间，用户的消息会直接发送给坐席，不经过 AI 处理
