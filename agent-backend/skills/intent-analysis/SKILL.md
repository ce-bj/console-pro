# 访客意向分析技能

## 工具说明

`analyze_visitor_intent` 会将当前完整对话历史交给后台分析 Agent 处理，返回：

- **需求类型**：价格咨询 / 案例索取 / 功能咨询 / 信息披露 / 购买意向（由配置决定，可为 null）
- **意向等级**：高意向 / 中意向 / 低意向 + 0–100 分数
- **判断依据**：一句话说明

分析结果同时写入后台，供 N2 坐席工作台实时展示。

## 调用时机（自行判断，不是每轮都调）

✅ **该调用**：
- 访客主动询问具体价格、版本对比或采购预算
- 对话已进行 **3 轮以上**，需要判断下一步策略
- 访客提到公司名称、团队规模、使用场景或决策周期等背景
- 考虑是否推进留资表单或转接人工销售顾问时
- 访客表达了明确意图（"想试试"、"准备采购"、"需要报价"）

❌ **不需要调用**：
- 首轮打招呼或纯基础功能询问（信息量不足，分析意义有限）
- 已完成留资，当前是售后或技术支持场景
- 访客刚回答了 confirm_dialog，正处于信息收集中间状态

## 结果使用策略

| 意向等级 | 分数范围 | 推荐策略 |
|---------|---------|---------|
| 高意向 | 75–100 | 直接推留资表单（`lead_capture_form`），或调用 `request_human_handoff` 转接销售顾问 |
| 中意向 | 45–74 | 继续深入介绍，引导 Demo 预约或用 `confirm_dialog` 了解采购背景 |
| 低意向 | 0–44 | 聚焦回答问题、建立信任，不推销；观察信号变化后再判断 |

## 使用示例

访客说"你们和 Salesforce 有什么区别？价格怎么算的？" 并已有 3 轮对话 → 调用 `analyze_visitor_intent` → 若返回"高意向"则自然过渡到留资流程：

> "根据您的关注点，我来帮您梳理一下对比要点……（回答完毕）顺便问一下，您这边大概什么时候有采购计划？方便的话可以安排一次专属演示。"

然后按渐进式留资技能操作。
