# 渐进式留资技能

## 触发条件（需同时具备明确意向信号，不是随口询价就触发）

**触发**（以下任一，但要求用户已有实质交互）：
- 用户追问了价格细节、版本差异，或主动对比多个方案
- 用户提到了具体的公司名称、团队规模、预算区间或部门场景
- 用户询问了私有化部署、实施周期、定制开发等深度问题
- 用户明确表示想要演示、试用、方案书或报价单
- 对话已进行 3 轮以上且用户持续提问（而非一问即走）

**不触发**：
- 对话开始阶段或访客随口打招呼
- 仅进行了 1 次询价，用户还未有进一步反应
- 用户明显只是随便看看，没有表现出选型意向

## 操作流程

### 第一阶段：用 confirm_dialog 了解背景（必须先做）

**重要：confirm_dialog 的问题和选项不要套用固定模板，要根据当前对话上下文自行拟定。**

原则：
- 问题要与用户刚才提的内容直接相关（问什么、怎么用、什么场景）
- 选项要贴合实际（行业、规模、用途等视情况选择最相关的维度来问）
- 一次只问一个维度，问完一个再视情况问下一个

示例（仅供参考，实际要按上下文来）：
- 用户刚问了私有化部署 → 可问"您目前倾向哪种部署方式？"
- 用户对比了入门版和专业版 → 可问"您的团队大概多少人？"
- 用户问了 AI 客服功能 → 可问"您主要想用在哪个业务场景？"
- 用户问了和某竞品的区别 → 可问"您现在在评估几款产品？"

调用格式：
```
confirm_dialog(
  question="根据对话上下文自拟的问题",
  options=["根据问题维度自拟的 3-4 个选项"],
  step_id="lead_step_1"
)
```

**重要：调用 `confirm_dialog` 后，立即结束本轮回复，不要再调用任何其他工具。**
等收到用户的选择作为下一条消息后，再根据回答决定下一步（再问一个维度，或进入第二阶段）。

### 第二阶段：收集联系方式

在明确意向后调用 `lead_capture_form`，只收集核心字段：

```
lead_capture_form(
  title="为您安排专属演示",
  description="填写后，我们的顾问会在 1 个工作日内与您联系",
  fields=["name", "phone"],
  optional_fields=["email", "company", "requirement"]
)
```

### 第三阶段：确认并告知后续

收到用户提交后，告知：
"感谢您的信息！我们的顾问会在 1 个工作日内联系您，安排专属演示。"

## 注意
- 不要在一次 `lead_capture_form` 调用中要求超过 5 个字段
- 必填仅限姓名和手机，其余均为可选
- confirm_dialog 的内容由你根据上下文判断，不要照抄示例
