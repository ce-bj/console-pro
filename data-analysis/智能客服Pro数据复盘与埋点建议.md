# 智能客服 Pro 数据复盘与埋点建议

> 数据来源：`data-analysis/` 4 张运营看板截图（截取于 2026-06-10 / 06-16）
> 覆盖范围：客户总览（日）、客户月活（月）、会话策略邀请（日）、客户行业占比、用户转化线索（周）、用户转化漏斗（总数）、知识库召回率（周）、AI 回复率（周）
> 目的：①评估现有数据能否回答核心运营问题 ②盘点缺失维度、规划埋点 ③提炼面向商务的传递要点
> 受众：产品/运营复盘 + 商务/销售

## 二、能不能回答你关注的问题（逐项判定）

下表用三档判定：🟢 现有数据可直接回答 / 🟡 只能部分回答、需推断或补字段 / 🔴 现有数据无法回答。

| 关注问题 | 判定 | 现有数据能给出什么 | 缺口 |
|---|---|---|---|
| **产品谁在用** | 🟡 | 行业分布（制造业过半）、PC/移动端有效行为客户数、运营中 559 家 | 缺客户规模、地域、套餐档位、所属销售/代理；无法画出"典型使用客户画像" |
| **用得怎么样** | 🟡 | 客户层：有互动率 73%、转线索率 41%；访客层：接待→互动 6.46%、线索转化率 12.6%~17.9%；**质量层：知识库召回率 ≈99%、AI 回复率 ≈87%（已有）** | 已有召回率/回复率，但仍缺 **RAG 准确率（答得对不对，非仅召回）、转人工率、满意度 CSAT**；质量指标也未按客户/行业下钻 |
| **改进的点在哪** | 🟡 | 邀请接受率仅 1.44%、各策略接受率 0.97%~2.48% 明显偏低 → 主动邀请话术/时机是明确改进点 | 缺漏斗每一跳的流失归因，无法定位"卡在哪一步、为什么流失" |
| **优点是什么** | 🟢 | 客户粘性高（73% 在用）、留资转化健康（互动用户 17.86% 转线索，行业基准很高）、运营客户稳步增长 | — |
| **缺点是什么** | 🟢 | 主动邀请接受率极低（≈1.4%）、连带率仅 2%、访客互动率仅 4% | 同上，缺归因 |
| **区域特性是什么** | 🔴 | 无任何地域字段 | 现有看板完全没有国家/地区/语言维度（系统底层有 IP/地区/语言，但未进数据分析看板） |
| **用得好的客户是谁** | 🔴 | 只有汇总数，没有按客户（账号）拆分 | 无法做客户分层榜单，识别不出标杆客户与流失风险客户 |
| **用得不好的是谁** | 🔴 | 同上 | 无法识别"买了不用 / 用了不转化"的客户 |
| **使用频率是什么** | 🟡 | 月活有"点击菜单活跃量""有效行为客户数"，可粗看月活 | 缺日活/周活、登录频次、会话频次的分布，无法算频率分层 |
| **核心用户是谁** | 🔴 | 无 | 缺 RFM / 活跃分层 / 价值分层，识别不出核心账号 |

**结论**：现有数据能回答"**整体好不好**"（盘子层面的趋势与转化），但回答不了"**谁好谁不好、为什么、在哪改**"（个体层面的分层与归因）。

根因有三：
1. **缺少"按客户下钻"的明细**——所有指标都是全站汇总，没有 account_id 维度，导致"谁在用、谁是核心、谁要流失"全部无解。
2. **质量层只有"召回率/回复率"，缺"准确率与满意度"**——已能看到知识库召回率(≈99%)和 AI 回复率(≈87%)，但"答得对不对(准确率)、用户满不满意(CSAT)、答不了时转人工的比例"仍缺；且现有质量指标是全站汇总，无法按客户/行业判断谁的体验差。
3. **缺少地域/属性维度**——底层系统已有 IP、地区、语言、所属企业（见系统现状梳理），但没有接入数据分析看板。

## 三、缺失维度与埋点建议（为后续补埋点）

按"先补能立刻提升决策价值、且系统已有底层数据"的顺序排优先级。

### P0｜客户分层（解决"谁在用、谁好谁不好、核心用户"）

- 维度：account_id、客户名称、行业、地区、套餐档位、开通时间、所属销售/代理。
- 指标：每客户的 会话数、互动访客数、转线索数、转人工数、知识库文档数、活跃天数。
- 用途：直接产出"使用排行榜 / 沉睡客户清单 / 流失预警清单"，这是当前最大缺口，且系统已有客户主档，接入成本低。
- 埋点：在现有"客户数据总览"增加按 account 拆分的明细表（可下钻）。

### P0｜AI 应答质量（解决"用得怎么样"，含你点名的 RAG 准确率）

> 已有：知识库召回率(≈99%)、AI 回复率(≈87%)。下面是"在此基础上还要补"的部分。

- **RAG 准确率追踪（关键补缺）**：召回率只回答"有没有找到知识"，不回答"答得对不对"。需对每次回答记录 `命中知识库片段 / 引用文档 id / 检索相似度分数 / 是否兜底`，并对回答做"有用/无用"打标（用户点踩、转人工、重复提问可作为弱标签），从而算出**准确率**（≠召回率）。
- **回复率归因**：已有 87% 这个总数，需补"未回复的 13% 卡在哪"——是没召回、还是召回了但模型没用上（解释召回 99% 与回复 87% 的 12pt 落差）。
- **转人工率 / 转人工原因**：触发转人工的会话占比及原因分布。
- **满意度（CSAT）**：会话结束后的评价采集（系统有"回复调研"技能，但看板无数据）。
- **质量指标下钻**：把召回率/回复率/准确率按 account、行业、地区拆开，定位"哪些客户体验差"。
- 用途：把"转化好"升级为"体验好 + 转化好"，也是对外证明产品力的硬证据。

### P1｜地域与语言（解决"区域特性"）

- 维度：访客国家/地区、语言（ZH_CN/EN…）、客户所在地。
- 指标：分地区的接待量、互动率、转化率、接受邀请率。
- 用途：底层已有 IP→地区、语言识别，只需把这两个字段带进转化看板即可解锁"区域特性"分析，几乎零额外采集成本。

### P1｜会话邀请归因（解决"改进点在哪"）

- 现状：邀请接受率仅 1.44%，5 类策略接受率全部低于 2.5%，是最明显的优化项，但看不出为什么。
- 埋点：记录每次邀请的 触发页面、触发时机（停留秒数/滚动深度阈值）、文案版本、设备端，支持 A/B 对比。
- 用途：把"邀请接受率低"从一个结论变成可优化的实验。

### P2｜使用频率分布（解决"频率、核心用户"补充）

- 指标：客户登录频次、会话频次的日活/周活/月活及分布，访客回访率。
- 用途：配合 P0 客户分层做 RFM，定义"核心客户"。

### P2｜漏斗逐跳与流失归因

- 把"接待 75854 → 互动 4900 → 线索"补全为"曝光→邀请→接受→互动→留资→转客户"每一跳，并记录流失节点。

## 四、面向商务的传递要点

商务侧有两个目的：**（1）增强售卖信心、促成交**；**（2）借商务向客户传递价值、促进客户用起来**。下面分别给出"可直接用"的话术素材，数字均来自本次看板。

### 目的一：增强售卖信心（对内/对潜在客户讲产品力）

1. **粘性证据**：运营中客户里 **73% 有真实互动**（409/559），不是买了吃灰的工具——这是 SaaS 续费率的先行指标。
2. **转化证据**：访客一旦和 AI 互动，**约 1/6 会转成线索**（互动用户线索转化率 12.6%~17.9%，最近一周 17.86%），对外贸获客是非常硬的 ROI 故事。
3. **规模与稳定**：售卖客户数稳步增长（783→807，6 天净增 24），接待用户量周级稳定在 50 万~60 万级别，产品已过 PMF 验证期、运行稳定。
4. **行业适配证据**：客户高度集中在**制造业（55%）+ 批发零售（17%）+ 科研技术服务（15%）**，合计近 90%。商务拓客时主打这三个行业的同行案例，转化效率最高。
5. **AI 能力证据**：**知识库召回率长期约 99%、AI 回复率约 87%**——可量化地证明"AI 真的能答、答得准"，比空泛说"我们有 AI"有力得多（注意：召回 99% 是"找得到知识"，对外可讲；回复 87% 仍有提升空间，对内当优化项）。

> 提醒：连带率仅 2.03%，是"已购其他应用的客户里有多少加购了智能客服 Pro"。这对内是机会点（交叉销售空间大），对外不必强调。

### 目的二：借商务向客户传递价值（让买了的客户用起来）

给商务一套"季度/月度客户价值小结"的口径，由商务转达给客户，制造"用得越多越值"的感知：

1. **晒成果**："本月 AI 为您接待 XX 位访客、主动发起 XX 次会话、沉淀 XX 条线索"——用客户自己的数字证明价值（需 P0 客户分层埋点后才能按客户给出）。
2. **促行动**：针对"买了不用 / 互动低"的客户，商务可带着数据回访："您的账号本月互动率低于同行业均值，建议补充知识库 / 调整开场白话术"——把数据变成一次有由头的客户触达。
3. **树标杆**：挑使用最好的客户做成案例，反向激励其他客户对齐。

> 当前限制：上述 1、2、3 都依赖"按客户下钻"的数据（P0），现有汇总数据还做不到。**这恰恰是推动补埋点的最强理由——补完 P0 客户分层，商务才能拿着每个客户自己的数字去促活、促续费、促加购。**

## 五、结论与下一步

- 现有数据**能回答"整体趋势好不好"，回答不了"谁好谁不好、为什么、怎么改"**，因为缺三类东西：按客户下钻的明细、AI 质量的"准确率/满意度"补全（召回率/回复率已有）、地域维度。
- **最高优先级**：补 **P0 客户分层** 和 **P0 AI 质量补全（准确率/CSAT/转人工，并下钻到客户）**。前者一次性解锁"核心用户/沉睡客户/商务促活"，后者在已有召回率/回复率之上补齐"答得对不对、用户满不满意"。
- **几乎零成本的速赢**：把底层已有的**地区、语言**字段接进转化看板，立刻解锁"区域特性"。
- **对商务**：现在就能用的，是整体粘性（73%）、互动转化（~17%）、行业集中度（制造业为主）、**AI 召回率 99% / 回复率 87%** 四组数字；想做到"按客户传递价值"，需先补 P0 埋点。

| 优先级 | 埋点项 | 解锁的关注问题 | 落地成本 |
|---|---|---|---|
| P0 | 客户分层明细（account 维度） | 谁在用/谁好谁不好/核心用户/频率 | 低（已有客户主档） |
| P0 | AI 质量补全（**准确率/CSAT/转人工**；召回率99%、回复率87%已有） | 用得怎么样/产品力证明 | 中 |
| P1 | 地域与语言 | 区域特性 | 低（底层已有） |
| P1 | 邀请归因 + A/B | 改进点（提升 1.44% 接受率） | 中 |
| P2 | 频率分布 / 漏斗逐跳归因 | 频率/核心用户/流失定位 | 中 |
