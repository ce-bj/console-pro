# 网站档案

一份档案对应 **一个网站**。它由 Agent 从知识库里已经有的知识总结出来，展示在知识库页面上。AI 运营助手每次对话读的，就是这一页。

知识库自己学习三类材料：客户网站前台页面、数字门户后台数据、客户上传的文档。网站页面或后台数据有更新，每天 0 点增量进入知识库。上传文档按知识库的入库进入。档案不直接读数字门户。

这一页写企业基本信息、主营业务、企业联系方式、企业资质和网站导航。每块下面的对应入口，是这些知识在数字门户里的来源。知识库里某个入口还没有相应知识，页面上就提醒客户去这个入口补充；同一块里其他入口已经有知识，总结先用已有的，缺的入口照样提醒。补完后要等增量学进知识库，下次总结才会写进来。总结时只使用知识库里已有的、和该入口相关的知识，不回后台对字段，也不规定这块必须出现哪些字段。

上一版按字段铺开的草稿见 `AI运营助手-网站档案-空结构.md`。以本文件为准。

页头只留网站名称、域名、主要语言、最近整理日期，用来分清是哪一个站。

---

## 1. 企业基本信息

**对应入口**

- 网站管理 → 网站设置 → 网站信息：网站名称、公司名称、公司介绍
- 网站管理 → 内容管理 → 介绍内容：标题或分类为公司简介、关于我们的已发布正文
- 网站管理 → 内容管理 → 发展历程：已发布的年份、事件、概要

**建议怎么总结**

把知识库里已有的企业身份、简介和历程收成一段企业基本信息。公司叫什么、在哪、什么时候、做什么，用知识里的原文，不另写一句定位。发展历程按时间收成几条「哪一年做了什么」，不把单条事件写成整站卖点。上面某个入口还没有知识，就提醒客户去该入口补充。

## 2. 主营业务

**对应入口**

- 网站管理→ 网站设置 → 网站信息：主营行业、经营模式、主营产品、主营业务介绍

**建议怎么总结**

用知识库里已有的行业、经营模式、主营产品、业务介绍和解决方案标题，写成这段企业的主营业务，写到品类，不写具体型号。解决方案只收标题，不收正文。上面某个入口还没有知识，就提醒客户去该入口补充。

## 3. 企业联系方式

**对应入口**

- 网站管理 → 内容管理 →企业网点：优先总部，没有总部则用已发布的网点

**建议怎么总结**

用来自企业网点的知识，收成一段企业联系方式。有总部用总部，没有则用已有网点。只写知识里出现过的地址、电话、邮编、网址、公众号，不新造邮箱。知识库里没有网点，就提醒客户去企业网点补充。

## 4. 企业资质

**对应入口**

- 网站管理 → 内容管理 →荣誉资质：已发布的名称、分类、概要
- 网站管理 → 内容管理 →介绍内容：标题或分类为资质、证书的已发布正文

**建议怎么总结**

把知识库里已有的荣誉收成名称列表，有概要就附原文里的一句。资质、证书类正文里，只摘能对上这些名称的句子，不补证书编号和有效期。上面某个入口还没有知识，就提醒客户去该入口补充。

## 5. 网站导航

**对应入口**

- 网站管理 → 网站设置 →导航管理

**建议怎么总结**

按知识库里已有的导航层级列出栏目。每个栏目用一句话说明它主要是什么，依据栏目名称和它挂接的内容来写。不把栏目下的正文贴进来。知识库里没有导航，就提醒客户去导航管理补充。
